# YuNet face detector for Touchdown

`face_detection_yunet_2023mar.onnx` is from the [OpenCV Zoo YuNet model](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet), distributed under the accompanying Apache 2.0 license in `OPENCV_ZOO_LICENSE`.

SHA-256: `8f2383e4dd3cfbb4553ea8718107fc0423210dc964f9f4280604804ed2552fa4`.

Touchdown uses it locally to find and track the central face for the optional face-refinement stage. It does not contact a face-recognition service or identify the person.
